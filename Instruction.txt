1) BUILD
   Push to GitHub → Actions builds → download from Releases.
   Put your logo at  app/src/main/assets/logo.png

2) TARGET APK — AndroidManifest.xml (before <application>):
   <uses-permission android:name="android.permission.INTERNET"/>
   <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
   <uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
   ⚠ NEVER write "android:targetApi" in any manifest (aapt error).

3) HOOK LINES (from MainActivity.smali → paste in target Activity onCreate):
   invoke-static {p0}, Lcom/TENIx/MODs/OpenDialogbox;->show(Landroid/app/Activity;)V
   invoke-static {p0}, Lcom/TENIx/MODs/UpdateDialogbox;->show(Landroid/app/Activity;)V

4) DEX STRING REPLACEMENT (MT Manager → dex → strings):
   REPLACE_FIREBASE_REALTIME_DB_URL → https://your-project-default-rtdb.firebaseio.com/
   REPLACE_FIREBASE_DB_SECRET       → your DB secret (optional if rules public)

5) FIREBASE RULES:
   { "rules": { "apps": { ".read": true, ".write": "auth != null" } } }

6) HOW THE UPDATE FLOW WORKS (V2)
   • App launch        → instant Firebase check → dialog (+ notification if new).
   • App running       → checks every 15s → CALL UPDATE shows notification
                         + dialog within ~15 seconds. NO app restart needed.
   • App fully closed  → notification appears on next launch (instant).
     (True push while closed needs FCM — impossible for injected dex.)

7) IMPORTANT
   • Notification image URL MUST be https:// (panel auto-fixes http).
   • Admin panel → open app → UPDATE → CALL UPDATE (press as many times
     as you want — every press fires a fresh notification).
   • Turn OFF stops the dialog but devices keep the last notification.
   • Update history (last calls) is stored in apps/{pkg}/history.

8) STABILITY — all network/JSON/UI code is try/catch protected.
   The host app can NEVER crash from this module. Guaranteed.
