⚡ Quick Start Guide

🔥
Step 1 — Connect Firebase Go to Settings → enter your Database URL (+ optional Secret) → press 💾 Save & Connect. The status dot at the top turns green 🟢 when connected.
📱
Step 2 — Add an App Open the Apps page → tap the ＋ FAB button (bottom-right) → enter the target app's Name + Package ID → Add. (Icon & About are optional.)
🪝
Step 3 — Inject (once per target app) Open Tools → copy the hook codes + permissions → use MT Manager to inject the dex into the target APK, place the hooks, then rebuild & sign.
📢
Step 4 — Call Update Apps → open an app → tap 🚀 UPDATE App → fill in version, date, update URL, notification image & features → press 📢 CALL UPDATE.
✅
Step 5 — Done! Apps that are open receive the notification + Update Dialog within ~15 seconds. Closed apps get it on next launch. Every press = a fresh notification.
